# 🔒 Sistema Embebido de Control de Acceso Biométrico

Este repositorio contiene el desarrollo integral de un sistema de control de acceso mediante lectura biométrica de huella dactilar, diseñado e implementado como parte de la formación en **Ingeniería en Computación (UNRN Sede Andina)**.

---

## 🚀 Descripción del Proyecto

El sistema reemplaza los métodos de autenticación tradicionales (teclados/contraseñas) por un esquema embebido de validación de huella dactilar y/o tarjetas RFID. Garantiza tiempos de respuesta eficientes, bajo consumo y control seguro sobre dispositivos periféricos.

### 🛠️ Tecnologías y Herramientas
* **Lenguaje:** C (Programación estructurada, tipos opacos, control de memoria)
* **Plataforma/Hardware:** Raspberry Pi / Microcontroladores & Sensor de Huella Dactilar
* **Entorno:** Linux / GCC / Make / GDB
* **Documentación:** Diagramas de bloques, especificación de requerimientos y pruebas de integración

---

## 📂 Estructura del Repositorio

* `Código del sensor/` y `códigos/`: Código fuente en C para la lectura, validación y comunicación con el sensor biométrico.
* `Informe de diseño/`: Arquitectura lógica y física del sistema embebido.
* `informe de requerimientos/`: Especificaciones funcionales y no funcionales del proyecto.
* `informe de testing/`: Protocolos de prueba, casos de testeo y validación de errores.
* `Funcionamiento de sensor/`: Diagramas de flujo y explicación del protocolo del sensor.
* `Póster/`: Material gráfico explicativo del proyecto.
